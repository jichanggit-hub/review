## 📐 我们怎么测

- **晚高峰优先**：白天速度任何机场都好看，只有 20:00–23:00 的数据有意义
- **来源标注**：每份测速报告都注明是**家宽实测**还是**运营方报告**，以及测试环境
- **解锁逐项验证**：只标记「稳定可用」，偶尔能用的一律不算解锁
- **每 GB 成本换算**：年付档折算月均后再比，不用「年付价冒充月付价」误导
- **不接受付费排名**：排序只看数据；本页链接为联盟链接（你的价格不变，我们获得少量佣金用于测速成本）
